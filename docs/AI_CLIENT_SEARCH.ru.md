# ИИ-поиск клиентов

Модуль находится во вкладке «Ещё» → «Поиск клиентов». Он отделяет найденного кандидата от подтверждённого клиента и не отправляет сообщения без действия владельца.

## Уже реализованная основа

- Настройки поиска: продукция, страны, минимальная партия, типы покупателей, языки и правило по посредникам.
- Задания поиска с фиксированной копией критериев и статусом выполнения.
- Кандидаты с рейтингом 0–100, объяснением рейтинга, контактами и датой проверки.
- Несколько подтверждающих интернет-источников для каждого кандидата.
- Статусы: новый, проверен, связались, переговоры, клиент, отказ.
- История изменения статуса и явное преобразование кандидата в клиента MRBA.
- Проверка готовности параметров и наличия `OPENAI_API_KEY` только на сервере.

## Принципы безопасности и качества

- Ключ OpenAI хранится в серверной переменной окружения и не передаётся мобильному приложению.
- Агент обязан сохранять URL источников и не должен придумывать контактные данные.
- Совпадения компаний удаляются по нормализованному домену сайта.
- Автоматическая отправка писем и сообщений отключена. Решение о контакте принимает владелец.
- Найденная компания не становится клиентом автоматически.

## Следующий этап

После получения параметров владельца и API-ключа подключается исполнитель поиска: получение открытых веб-источников, структурированный ответ модели, проверка доменов и контактов, подсчёт рейтинга, лимиты запросов и учёт стоимости.
