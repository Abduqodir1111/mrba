# ИИ-поиск клиентов

Модуль находится во вкладке «Ещё» → «Поиск клиентов». Он отделяет найденного кандидата от подтверждённого клиента и не отправляет сообщения без действия владельца.

## Уже реализованная основа

- Настройки поиска: продукция, страны, минимальная партия, типы покупателей, языки и правило по посредникам.
- Задания поиска с фиксированной копией критериев и статусом выполнения.
- Кандидаты с рейтингом 0–100, объяснением рейтинга, контактами и датой проверки.
- Несколько подтверждающих интернет-источников для каждого кандидата.
- Статусы: новый, проверен, связались, переговоры, клиент, отказ.
- История изменения статуса и явное преобразование кандидата в клиента MRBA.
- Проверка готовности параметров и наличия `OPENAI_API_KEY` только на сервере.
- Локальный исполнитель Responses API с веб-поиском; запуск выполняется из приложения и продолжается в фоне.
- Стартовый профиль MRBA: латунные и медные прутки, Узбекистан, Казахстан, Таджикистан и Кыргызстан, партия от 1000 кг.
- Посредники исключены. Сохраняются только производственные предприятия с найденным email, Telegram или WhatsApp.
- Для каждого кандидата сохраняются ссылки-доказательства и готовый текст обращения на языке найденного сайта.
- WhatsApp и Telegram показываются только при наличии явной опубликованной компанией ссылки; по одному номеру Telegram не угадывается.
- Перед каждым запуском владелец выбирает количество кандидатов от 1 до 50.
- Во время поиска приложение каждые две секунды показывает этап, время, цель и число найденных кандидатов.
- По умолчанию запрашивается 1 кандидат. Активный поиск можно отменить из карточки прогресса; запрос OpenAI прерывается, статус становится «Отменён».
- Все ранее найденные названия и домены передаются в список исключений; сервер повторно проверяет и не сохраняет дубликаты. Для добора новых кандидатов допускается до трёх поисковых проходов.
- Кандидаты сортируются от новых к старым; результаты последнего успешного поиска выделяются зелёным цветом.
- Поиск выполняется как последовательность этапов: обнаружение предприятий, расширение выборки, проверка сайтов и контактов, оценка и сохранение.
- Оценка учитывает соответствие продукции, размер и возможную партию, наличие ответственного контакта, качество источников и соответствие географии. В карточке сохраняются причины соответствия и риски.
- Агент ищет отдел закупок, снабжения, коммерческого директора, директора производства или владельца; имя и должность сохраняются только при наличии источника.
- Для кандидата доступны статусы «Ответил» и «Запросил цену», заметки, дата следующего контакта и история работы.
- Предыдущие успешные, переговорные и отклонённые кандидаты с заметками передаются следующему поиску как опыт агента.
- Персональное обращение формируется на языке сайта и учитывает деятельность найденной компании и продукцию MRBA.

## Принципы безопасности и качества

- Ключ OpenAI хранится в серверной переменной окружения и не передаётся мобильному приложению.
- Агент обязан сохранять URL источников и не должен придумывать контактные данные.
- Совпадения компаний удаляются по нормализованному домену сайта.
- Автоматическая отправка писем и сообщений отключена. Решение о контакте принимает владелец.
- Найденная компания не становится клиентом автоматически.

## Локальный запуск

Укажите `OPENAI_API_KEY` в корневом `.env`. При необходимости модель меняется через `OPENAI_MODEL`; по умолчанию используется `gpt-5.4-mini`. После перезапуска API кнопка «Начать поиск» станет доступна. Ключ никогда не передаётся в мобильное приложение.
